A fast drop-in for csv-reader 1.0.0: a single-pass, slice-based CSV reader that answers
exactly as the reference on every case — including its broken-row policy (stray CRs,
quote junk, unterminated quotes, short and long rows) — at about 2.5x the reference's
speed on the practice set. Plain lines split on commas in one go; anything with a quote
or a stray CR goes through indexOf-based field scanners.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
